# Codesphere

> Codesphere is a European-built sovereign cloud platform that deploys and operates applications across on-premises, hybrid, and public-cloud infrastructure from a single control layer, without Kubernetes expertise or vendor lock-in. Its Public API (`https://cloud.codesphere.com/api`) manages workspaces, CI/deploy pipelines, landscapes, managed services, domains, teams, organizations, secret vaults, SSH keys, and usage.

## API
- [Codesphere Public API (OpenAPI 3.0.0)](https://cloud.codesphere.com/api/swagger-ui/swagger-ui-init.js): 80 operations across clusters, domains, managed-services, metadata, organizations, ssh, teams, usage, vault, and workspaces.
- Interactive docs: [Swagger UI](https://cloud.codesphere.com/api/swagger-ui) and [Scalar UI](https://cloud.codesphere.com/api/scalar-ui).
- Base URL: `https://cloud.codesphere.com/api`
- Auth: `Authorization: Bearer <Personal Access Token>` (User Settings > API Keys).
