Codesphere is a European-built sovereign cloud platform that lets organizations deploy and operate applications across on-premises, hybrid, and public-cloud infrastructure from a single control layer, without Kubernetes expertise or vendor lock-in. Its Public API manages workspaces, CI/deploy pipelines, landscapes, managed services (PostgreSQL, Valkey, OpenSearch, RabbitMQ, DocumentDB, object storage, virtual Kubernetes clusters), custom domains, teams, organizations, secret vaults, SSH keys, and usage. A first-party `cs` CLI, a Go managed-services SDK, a GitHub deploy Action, and a VS Code extension wrap the same REST contract. Codesphere is ISO 27001 certified and SOC 1 & 2 attested. Surfaced as a portfolio company of Creandum and enriched from its own public developer surface.

**Areas:** Company · Software-as-a-Service · Cloud · Deployment · Developer Tools · Platform-as-a-Service · Infrastructure · Sovereign Cloud · CI/CD · Managed Service

## How this profile is made

API Evangelist profiles a company's public API surface the way a developer would find it: the website, developer portal and documentation, the specifications it publishes, its public repositories, and its pricing, status and changelog pages. From that it derives the properties above — contracts split per API, workflows, schemas, collections, governance rules, plans and rate limits — and scores them against the published [Kin Score rubric](https://github.com/api-evangelist/kin-score).

The artifacts are published on [APIs.io](https://apis.io), not in this repository. This repository is the public record for Codesphere: the place to say something is wrong, missing or out of date, and to ask for a re-score or a removal.
